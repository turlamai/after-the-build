第三部 · 程序与操作系统

终端、Shell 和命令行究竟是什么

我们平时通过点击图标启动软件，通过选择菜单完成操作。但计算机也可以接受以文字表示的操作要求。

例如，在 macOS 或 Linux 上，可以输入：

pwd

在常见 Shell 中，它会显示当前工作目录。这里的 pwd 是一个命令名称，不是处理器的机器指令。

三个容易混淆的概念

命令行界面（Command-line Interface，CLI）是一种通过文字命令及参数进行交互的方式。

终端（Terminal）是用于提供文本输入与输出的环境。我们常见的终端窗口是一种应用，它能够显示命令执行时产生的文字，也接收键盘输入。

Shell 则是处理命令文字、执行相关语法并组织程序启动的软件。例如 Bash、Zsh 和 PowerShell 都属于 Shell。

在一个典型的交互过程中，用户向终端输入文字，Shell 接收并解释文字，然后执行内建命令或启动相应程序。程序产生的输出可以再显示在终端中。

命令后面为什么还可以写文字

如果已经安装 Git，可以使用：

git --version

这里 git 是要执行的命令，--version 是传递给 Git 的选项。Git 根据自己的接口规定解释这个选项，并输出版本信息。

Shell 在启动程序之前还可能处理引号、变量展开和其他语法。因此，同一个命令在不同 Shell 中不一定能够原样使用。

系统通常通过 PATH 等环境变量提供程序查找位置。环境变量（Environment Variable）是程序运行环境中的名称和值。PATH 只是其中一个常见变量。

当出现找不到命令的提示时，可能是程序没有安装，也可能是查找路径不正确。它与程序成功启动后报告执行错误属于不同情况。

程序怎样告诉外部自己是否执行成功

许多命令行程序在结束时会返回一个数值，称为退出码（Exit Code）。通常 0 表示正常完成，非零表示其他状态，具体含义由程序规定。

进程还可以通过标准输入（stdin）接收信息，通过标准输出（stdout）及标准错误（stderr）输出文字或数据。

Shell 可以把一个程序的输出连接到另一个程序的输入，这种连接称为管道（Pipe）。也可以改变输入输出的目的地，例如将输出保存到文件，这叫重定向（Redirection）。

重定向可能覆盖已有文件，不要在不了解目标路径时执行。

一个不修改文件的练习

在 macOS 或 Linux 的 Bash、Zsh 中尝试：

pwd
ls

在 Windows 的 PowerShell 中尝试：

Get-Location
Get-ChildItem

观察当前目录和目录中的内容。上述操作通常只读取信息，不修改文件。

如果安装了 Python，可以在终端执行 python --version 或 python3 --version，观察是否能找到相应程序。未安装时不需要为了阅读这一章额外安装软件。
