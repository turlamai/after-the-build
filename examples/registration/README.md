# 活动报名：本机教学项目

Python 3.10+，仅使用标准库。进入本目录，运行：

```sh
python3 app.py
```

访问 http://127.0.0.1:8000/，使用虚构姓名。Ctrl+C 停止服务。

测试：

```sh
python3 -m unittest -v
```

数据库默认保存于本目录 registration.db。测试使用独立临时文件，不接触运行数据。容量固定为 20。请求标识仅用于幂等，不用于身份认证；刷新页面会丢失尚未确认请求的前端临时标识。持久化测试验证重新打开文件，不模拟断电。

本项目不含登录、取消、真实个人信息处理、生产部署或完整安全保护。不要直接开放公网。Python 标准库 HTTP 服务仅用于实验。部署真实产品前应重新评估需求、授权、输入与资源限制、服务运行环境及 HTTPS 等条件。
