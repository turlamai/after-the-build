# 第二部概念依赖记录

| 单元 | 前置 | 新建概念 | 后续用途 |
|---|---|---|---|
| 电路怎样完成判断 | 位、布尔值、真值表 | 晶体管的控制作用、抽象、逻辑门、半加器、全加器、选择器 | 运算电路 |
| 怎样记住数字 | 逻辑门、状态 | 组合逻辑、时序逻辑、时钟、触发器、寄存器、写入使能 | 处理器 |
| 怎样定位数据 | 字节、寄存器、二进制 | 存储器地址、读写、总线、字节序 | 指令、网络协议 |
| 数字怎样成为程序 | 编码、地址、寄存器、运算 | 指令、操作码、操作数、程序、PC、分支、ISA | 执行、编程语言 |
| CPU 如何执行 | 上述所有单元 | CPU、ALU、控制逻辑、取指、译码、频率、核心 | OS、性能 |
| 内存与硬盘 | 存储、CPU、容量 | 易失性、非易失性、RAM、SSD、HDD、缓存、局部性 | 文件、虚拟内存、性能 |
