# 第五部知识依赖记录

29 网络通信：字节、编码、设备接口 → 物理通信、协议、分层。
30 局域网：网络接口、协议 → LAN、Ethernet、MAC、帧、交换机。
31 IP 地址：二进制位、链路地址 → IPv4/IPv6、前缀、子网、ARP、DHCP。
32 路由：IP 地址及前缀 → 网关、下一跳、路由表、互联网、NAT。
33 传输：IP 包、通信规则 → TCP、UDP、确认、重传、字节流和数据报。
34 端口与套接字：进程、系统接口、传输 → 端口、绑定、监听、连接、客户端和服务端。
35 DNS：名称、地址、缓存 → DNS、解析器、权威记录、TTL。
36 HTTP：传输、端口、域名、接口 → 请求与响应、方法、状态码、URL。
37 浏览器：GUI、事件、HTTP → HTML、CSS、JavaScript、DOM、来源、CORS。
38 Web 应用：模块、API、共享状态、HTTP → 前端、后端、共享业务处理。
39 localhost：前述全部网络概念 → 回环地址、监听范围、部署及分层诊断。

前置边界：NAT 只提前介绍端口的用途，在 34 章建立正式模型；HTTPS 在密码学部分深化；并发报名的完整数据保证在数据库事务部分建立。示例使用保留域名和文档地址，HTTP 示例为教学文本，不含真实个人数据。新增实验、链接和配图仍待集成验证。
