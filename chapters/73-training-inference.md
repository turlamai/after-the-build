# 模型怎样从数据中学习，又怎样被使用

上一章建立了一个只有两个参数的预测模型。现在假设模型预测某项活动会收到 8 条报名，而真实结果是 10 条。

我们怎样将这个差异转化为可以计算的调整依据？

## 用数值描述预测误差

最简单的办法之一是计算预测值与实际值的差，再计算差的平方。预测为 8，实际为 10，平方误差为 4。

用于度量模型输出与目标之间差异的计算规则，通常称为损失函数（Loss Function）。

我们可以尝试不同参数，比较得到的总损失。寻找能够使目标函数变小的参数的过程属于优化（Optimization）。

下面的程序不使用任何机器学习框架，只尝试几组整数参数：

```python
samples = [(1, 5), (2, 7), (3, 10)]
best = None

for a in range(5):
    for b in range(6):
        loss = sum((a * x + b - y) ** 2 for x, y in samples)
        if best is None or loss < best[0]:
            best = (loss, a, b)

assert best == (1, 2, 3)
print(best)
```

预期输出 (1, 2, 3)，分别表示损失、参数 a 和参数 b。实验只展示有限范围内搜索参数的机制，不代表大型模型实际采用这种搜索方法。

## 训练和推理解决不同的问题

根据数据调整模型参数的过程通常称为训练（Training）。使用已经建立的模型，根据新的输入计算输出，通常称为推理（Inference）。

推理不必重新进行完整训练。例如，已经确定 a 和 b 后，我们可以直接预测宣传 4 次时的报名人数。

对于现代神经网络，常见训练过程使用能够计算参数调整方向的数学方法，并反复处理大量数据。神经网络（Neural Network）由许多可组合的数值变换构成，可以通过大量参数表示复杂关系。这里不要求读者先掌握微积分。

## 参数怎样沿着误差方向改变

前面的整数搜索有两个同样达到最小损失的参数组合：(2, 3) 与 (3, 1)。程序保留首先找到的结果，并不代表它找到了唯一答案。

对于连续参数，可以通过梯度（Gradient）表示损失随各参数变化的局部方向。梯度下降（Gradient Descent）沿着降低损失的方向调整参数，调整幅度受学习率（Learning Rate）影响。

先考虑只有一个参数的模型，预测值为 w × x。令 x=2，目标 y=6，初始 w=1，损失为 (2w−6)²。导数（Derivative）描述一个数值函数在某一点附近的变化率。例如 w 增加很小的一段距离时，可以用损失的变化量除以 w 的变化量估计这个变化率。对于本例的平方损失，导数为 4(2w−6)。

当 w=1 时，导数为 −16，说明在这一点附近增加 w 可以降低损失。若学习率为 0.1，第一次更新得到 1−0.1×(−16)=2.6。此时预测值从 2 变成 5.2，损失从 16 降到 0.64。再重复同样的计算，参数逐渐接近 3。

不熟悉微积分的读者可以先根据这几个数字理解更新过程：导数给出局部变化率，学习率调节更新幅度。多个参数对应多个这样的变化率，它们组成梯度。

```python
w = 1.0
for _ in range(20):
    gradient = 4 * (2 * w - 6)
    w -= 0.1 * gradient
assert abs(w - 3) < 0.000001
```

这里逐次调整后，预测趋近目标 6。真实神经网络包含大量相互连接的数值运算，常用反向传播（Backpropagation）计算损失对参数的梯度，并由优化器决定如何更新参数。

本例只展示一个可微的简单模型。真实训练并不保证每一步损失都下降，也不保证找到全局最优结果。

## 为什么不能只检查训练过的数据

如果模型只记住曾经看到的例子，它可能在这些例子上表现很好，却无法正确处理新的活动。

模型在训练之外的数据上保持有效表现的能力称为泛化（Generalization）。

过度适应训练样本中的偶然特点，以至于新数据表现下降，称为过拟合（Overfitting）。

因此，评价模型时需要适当区分用于训练的数据和用于检验表现的数据。还要考虑实际使用环境是否与评价条件相近。

## 语言模型的任务是什么

语言模型（Language Model）对语言序列进行建模。许多现代生成式语言模型可以根据已有序列，计算下一个语言单位可能是什么。

大型语言模型（Large Language Model，LLM）通常具有大量参数，并经过大规模训练。这些模型的训练目标及后续调整方式可以包含多个阶段，不能简单归结为一个固定流程。
