# 亲自运行一个完整的小型 Web 应用

本书仓库的 examples/registration 目录包含完整教学项目：

- app.py：HTTP 处理和数据库操作。
- index.html：浏览器界面及请求代码。
- test_app.py：业务、持久化和 HTTP 接口测试。
- README.md：运行方法与适用范围。

在取得本书源代码后，进入该目录。确认安装 Python 3，再启动：

```sh
python3 app.py
```

Windows 用户可根据安装方式使用 python 或 py -3。

在本机浏览器打开 http://127.0.0.1:8000/。填写虚构姓名并提交，然后观察剩余人数。

服务默认仅绑定回环地址。关闭终端中的服务后，数据库文件 registration.db 仍然存在。再次启动时，已经成功保存的记录应继续存在。

不要使用真实个人信息，不要将本实验服务直接开放到公网。

## 观察一次请求

打开浏览器的开发者工具，找到网络请求记录。提交报名时，前端向 /api/registrations 发送 POST 请求，消息体采用 JSON。

后端读取姓名和请求标识，验证格式，再调用数据库操作。成功后，前端重新读取 /api/status，使显示与数据库状态重新同步。

![报名请求的执行顺序](../assets/intro-product-request.svg)

从这里可以观察前面各部的知识如何共同发挥作用：字符串编码、HTTP、进程、SQL、事务及事件处理都处于同一条执行路径上。

## 如何阅读源码

先阅读 app.py 中的 register 函数，理解业务约束；再阅读 Handler，了解 HTTP 如何转换为函数调用；最后阅读 index.html，理解浏览器如何发送请求。

不需要第一次就理解每一行。可以先观察运行结果，再沿着具体请求逐层查找实现。
