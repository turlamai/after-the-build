# 第 24 章 五十个问题：技术理解与工程验收

> 不仅要知道术语，还要能够解释机制、判断方案，并提供验证证据。

## 一、使用方法

以下问题分为十组，每组五题。先尝试独立回答，再阅读对应章节。概念题应能给出定义、机制和反例；工程题应能给出具体方案、风险及验收证据。不能用「AI 说可以」替代验证。

## 二、计算机与操作系统（第 1—5、7 章）

1. CPU 主频、核心数量和指令集架构分别描述什么？（主频是时钟周期频率，不等同指令吞吐量；核心提供执行资源；ISA 定义软件可见指令及相关行为。）
2. RAM、Cache 和 SSD 的职责与生命周期有什么区别？（前两者主要服务运行时访问，SSD 用于持久化；具体速度和容量因实现而异。）
3. 程序、进程与线程如何关联？（进程是运行实例，线程是执行序列，同进程线程通常共享地址空间。）
4. 为什么同一个相对路径在不同工作目录下可能得到不同结果？（解析基准不同。）
5. 编译器、运行时、操作系统和硬件分别承担什么职责？（转换程序表示、提供执行支持、管理资源、执行指令；具体边界因实现而异。）

## 三、软件与数据（第 1、4、5、8、17 章）

6. Web 应用中的前端、后端和 API 各自承担什么职责？（交互与展示、服务端业务处理、组件交互契约。）
7. 为什么终端、Shell 和 CLI 程序不是同一概念？（文本交互环境、命令解释器、实际执行功能的软件。）
8. Unicode、UTF-8 与 JSON 如何区分？（字符标准、字节编码、数据交换格式。）
9. 为什么编号 001 不一定应使用数值类型？（编号的前导零可能具有语义。）
10. 数据库主键、外键、唯一约束与事务解决什么问题？（标识记录、引用关系、唯一性、逻辑工作单元。）

## 四、网络与云计算（第 9、10 章）

11. IP 地址、端口、域名和 DNS 分别负责什么？（网络寻址、传输端点识别、名称、名称解析等记录查询。）
12. 为什么 localhost 无法直接作为他人的访问地址？（它通常解析到访问设备自己的回环地址。）
13. TCP、UDP、TLS 和 HTTP 之间有什么关系？（传输协议、传输安全机制、应用协议；HTTP/3 使用 QUIC。）
14. 如何区分 DNS 错误、连接失败和 HTTP 500？（分别检查解析、连接、应用响应证据。）
15. 虚拟机、容器、PaaS 和 Serverless 为什么不属于同一个分类维度？（隔离机制与服务责任模型不同。）

## 五、算法与性能（第 6、16 章）

16. O(n)、O(n²) 和 O(2^n) 的增长趋势有何区别？（线性、平方、指数。）
17. 延迟与吞吐量为什么需要分别测量？（单次完成时间与单位时间工作量不同。）
18. 为什么 P95 比单独使用平均值更有诊断价值？（它能反映较慢请求的分布特征。）
19. 索引和缓存有什么区别，分别引入哪些维护成本？（查询结构与可复用副本；写入成本、容量、失效等。）
20. 如何证明优化有效？（控制环境和输入，对比基线与新版本，验证正确性及性能指标。）

## 六、AI 与 Agent（第 11、12 章）

21. Token、模型参数和上下文窗口分别是什么？（序列单位、学习所得数值、单次处理容量。）
22. 训练、推理与 RAG 有何区别？（更新参数、使用参数、检索并提供外部上下文。）
23. 为什么模型可以生成不存在的 API？（生成结果不等于已经过事实核验。）
24. Tool Calling、MCP 和 Agent 有何关系？（调用机制、连接协议、结合模型与执行流程的系统。）
25. 如何验证 Agent 声称完成的任务？（检查变更、工具结果、测试、退出码及实际系统状态。）

## 七、构建、版本与部署（第 13、18 章）

26. 构建、发布、部署及 CI/CD 的职责如何区分？
27. Git 工作区、暂存区、本地提交和远程分支是否已经同步？
28. 依赖清单、锁定文件与运行时版本是否能够支持稳定构建？
29. 当前生产服务运行的是哪个 Commit 或发布产物？如何证明？
30. 发布失败后如何恢复？数据库迁移是否允许恢复旧应用？

验收证据：版本标识、构建日志、测试报告、部署记录、配置差异及恢复方案。

## 八、安全与密码学（第 15、19、20 章）

31. 是否区分认证与授权，并在服务端验证对象级访问权限？
32. API Key、访问令牌和私钥分别在哪里保存、何时失效？
33. 是否使用适当的参数化查询、输出编码和 CSRF 防护？
34. 加密、哈希、MAC 和数字签名分别提供什么安全属性？
35. 用户密码是否使用适当的密码哈希？TLS 及密钥管理是否采用成熟方案？

验收证据：权限矩阵、负向测试、脱敏配置、依赖审查和安全设计记录。

## 九、数据与隐私（第 17、21 章）

36. 数据分别保存在浏览器、本地文件、数据库还是对象存储？
37. 是否区分备份、复制、同步与导出？
38. RPO 和 RTO 如何定义，恢复演练能否满足目标？
39. 数据收集、共享、保留和删除是否有明确目的及责任人？
40. OAuth 授权范围、Cookie 属性与第三方数据传输是否经过检查？

验收证据：数据流图、字段清单、恢复演练报告、访问权限及保留策略。

## 十、质量与成本（第 14、16、22 章）

41. 功能需求、非功能需求和验收标准是否可观察、可验证？
42. 单元、集成、端到端及回归测试是否覆盖关键风险？
43. 故障是否记录版本、环境、复现步骤、日志及预期结果？
44. 是否按实际用量建立成本模型，并区分预算告警与硬配额？
45. 是否记录架构决策、候选方案、约束及专业审查边界？

验收证据：需求规格、测试用例及实际结果、成本计算、ADR 与风险清单。

## 十一、运行维护与交付（第 23 章及全书）

46. 是否定义服务指标 SLI、目标 SLO 及必要的 SLA？
47. 监控、告警、日志与追踪是否能识别真实用户影响？
48. 域名、证书、依赖、备份、权限和费用由谁负责维护？
49. 发生事故时是否存在保全证据、控制影响、恢复、验证及复盘流程？
50. 项目能否由其他人独立接手、重建、部署、恢复或正式下线？

验收证据：维护清单、运行手册、告警测试、交付文档及退役计划。

## 十二、综合实践

选取一个使用虚构数据的活动报名应用。按照第 1—23 章知识建立需求、架构、数据模型、接口、代码仓库、测试环境及运行方案。让 Agent 实现后，使用上述五十问审查交付。对不适用项说明原因，对尚未验证项明确标记，不将未执行的操作视为通过。

能够解释设计取舍、用证据判断结果，并知道何时需要专业审查，才是本书的学习目标。
