# 浏览器怎样把网络数据变成网页

如果服务器返回数字 3，浏览器可以直接显示这个字符。但真正的报名页面还需要标题、姓名输入框、确认按钮及相应交互行为。

这些内容怎样从网络上的字节变成屏幕上的界面？

## HTML 描述文档结构

浏览器能够理解超文本标记语言（Hypertext Markup Language，HTML）。HTML 使用规定的标记表达文档中的标题、段落、表单等结构。

例如：

```html
<!doctype html>
<html lang="zh-CN">
<meta charset="utf-8">
<title>报名活动</title>
<h1>活动报名</h1>
<p>剩余名额：3</p>
<label>姓名 <input name="name"></label>
<button type="button">确认报名</button>
</html>
```

这个页面可以显示标题、文字、输入框和按钮，但按钮还没有真正的报名处理行为。

将示例保存为 UTF-8 编码的 .html 文件并使用浏览器打开，可以观察这些基本结构。它不需要事先部署服务器。

## 样式和行为是另外两类规则

层叠样式表（Cascading Style Sheets，CSS）提供描述网页外观及布局的规则。

例如，我们可以规定标题的大小、页面边距，以及按钮在不同窗口宽度下的排列方式。

JavaScript 是浏览器广泛支持的一种编程语言。它可以在浏览器提供的执行环境中处理事件、修改文档状态，并在相应限制下发送网络请求。

这正好连接第四部的知识：界面部件负责显示和交互，事件处理函数负责根据事件执行操作。

HTML、CSS 和 JavaScript 并不是同一种语言的三个名称。它们主要解决的问题不同。

## 浏览器需要完成哪些处理

浏览器取得 HTML 后，会解析文档并建立相应的结构表示。常见的文档对象模型（Document Object Model，DOM）为程序访问和修改文档提供接口。

浏览器根据文档结构、样式和可用空间等信息组织显示，还需要处理资源加载、文字绘制、用户输入和脚本执行。

这些工作可以交错进行，并非所有页面都遵循一个简单的完全串行流程。

## 浏览器为什么不只是一个下载工具

网页中的 JavaScript 运行时能够请求浏览器提供的功能，但不能因此随意读取电脑上的任何文件，也不应该不受限制地访问其他网站的数据。

浏览器通过权限、来源隔离等机制限制网页能力。

来源（Origin）通常由方案、主机和端口组成。不同来源之间的访问受到相应安全规则限制。跨来源资源共享（Cross-Origin Resource Sharing，CORS）使服务端能够声明某些允许的跨来源读取条件。

这里先建立概念，不要求读者记住所有浏览器安全规则。后面的安全章节将继续解释这些限制为何必要。
