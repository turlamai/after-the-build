# 数据怎样跨越不同的网络

假设报名程序运行在办公室的一台电脑上，而申请者位于另一个网络。他们不再连接同一台交换机。

上一章已经建立了 IP 地址和网络前缀的概念。接下来需要回答：当目标地址不属于本地直连网络时，数据该交给谁？

## 路由器和下一跳

能够在不同 IP 网络之间转发 IP 包的设备或软件称为路由器（Router）。

计算机根据自身的路由配置决定怎样发送数据。对于没有更具体匹配路径的目标，常见家庭电脑会选择默认路由（Default Route），将数据交给配置好的默认网关。

例如，本机地址为 192.168.1.23/24，网关为 192.168.1.1。目标地址如果不匹配本地直连网络或其他更具体的路由，系统可能将数据交给这个网关。

网关是当前路径中的下一跳（Next Hop），并不是最终的业务接收方。

路由器收到 IP 包后，根据自己的路由表（Routing Table）选择下一段路径。在通常的 IP 转发中，每经过一段以太网链路，链路层地址会按该段通信需要重新组织，而 IP 目标地址通常保持不变，除非涉及地址转换等机制。

## 互联网不是一台中央交换机

互联网（Internet）是由大量相互连接的网络组成的系统。不同组织管理自己的网络，并通过相应的路由机制交换可达信息。

发送者通常不必预先列出每一台经过的路由器。路径由网络中的转发决定，并且可能随着网络状态变化。

IP 包在传输中还可能被丢弃。IP 本身并不保证每一个包一定到达，也不保证一组包按照发送顺序到达。

## 家庭网络为什么能够共享一个公网地址

许多家庭 IPv4 网络使用私有地址。家庭路由设备常使用网络地址转换（Network Address Translation，NAT），并结合端口转换，让多个内部通信流共享对外地址。

端口是区分传输层通信的重要标识，将在后面的章节详细说明。这里仅需要知道转换设备可以保存通信映射，以便将返回的数据交给正确的内部通信流。

这也解释了为什么外部设备不一定能主动访问家庭内部的服务：仅知道内部私有地址，通常不足以建立公网可达路径。

是否需要公网地址、转发规则或其他连接方式，还取决于运营商网络、系统防火墙及部署方案。IPv6 网络也并不必然需要与 IPv4 相同的地址转换方式。

## 网络连通不等于业务可用

能够到达某个 IP 地址，只说明通信所需的部分条件可能成立。该设备是否运行报名服务、服务是否允许访问、消息格式是否正确，仍然是另外的问题。
